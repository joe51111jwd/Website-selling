`public/media/section/*`, `src/media/manifest.json`.

1. **lines-b44.json `fresh`** (mock) points at segment 1, the bay's bottom wall (y ≈ 0.84). 07's freshly
   snapped line in b44 is the one at y ≈ 0.52, x ≈ 0.40 → 0.71 (mock frame). A-105 puts the SECTION A–A
   cut marker on `fresh`, and the plan-cut registration uses it too, so please make `fresh` that line.
   Convention A4 assumes (please confirm or correct): `fresh.a` = the robot / hand end, `fresh.b` = the
   chalk-reel end; both normalised 0..1 of the same registered frame as `plan-b44`.
2. **`gridlines[]`** is empty in the mock; A4 derives axis-aligned gridlines from `segments` when it is
   empty (cluster by angle, merge within 0.02). If you ship it, A4 expects
   `{ axis: 'x' | 'y', at: number, from: number, to: number }` (normalised). Any other shape: tell me.
3. **trace-t43.svg**: A4 assumes its `viewBox` (0 0 1000 1000) maps to the FULL registered plan frame of
   `plan-b43` (same space as `borderRect`), strokes only, any colour (A4 recolours it chalk-blue via
   `mask-image`, so keep it fill="none" with strokes ≥1 px at 1000 units). The mock rectangle sits at
   x 560–860, y 120–520, but the taped sheet in the b43 poster is at about x 615–880, y 470–815 of 1000.
4. **Section depth range.** SECTION A–A maps the slider `s` (0 = camera end, 1 = robot end) to
   `uSlice = mix(nearD, farD, s)`. There is no section meta yet; A4 uses nearD = 0.92 and farD = 0.16
   measured from the mock `sec-c34-depth.png`. Please add `nearD`/`farD` (and `w`, the threshold band) to a
   tiny `sec-c34-meta.json` (id `sec-c34-meta`) when D3 runs; A4 reads it if present.
5. **sec-near / sec-mid / sec-far** (no-GL stills) should be the exact output of A4's shader
   (`src/sheets/sliceMaterial.ts`) at s = 0.1, 0.5 and 0.9, so GL and no-GL match. The simplest way:
   `scripts/capture.mjs` → `?capture&sandbox=…` scene **`slice`** with t = 0.1, 0.5, 0.9 (A4 registers it:
   duration 1, t = s), cropped to the section view box `[data-capture-crop="slice"]`. Or ask me for a
   node/python port of the shader.
