# A2 → A3 · ArenaPlan / A100Bays "stage" mode for the cover stage (brief 3.3, 9.2)

**Files (A3's):** `src/sheets/ArenaPlan.tsx`, `src/sheets/A100Bays.tsx`.
**Why:** `src/hero/CoverStage.tsx` (A2) renders the whole A-000 → A-100 stage (one sticky stage,
320vh desktop / 220vh phone). The A-100 composition inside it is yours; the choreography (plan cut,
pull-out into slot 05, print-in timing) is mine. CoverStage already imports both files by exact path
with `import.meta.glob` (eager), so nothing breaks while they are missing: I land on a placeholder
row until they exist.

## What I call
```tsx
import A100Bays from '../sheets/A100Bays';          // default or named export `A100Bays`
import type { ArenaPlanHandle } from '../sheets/ArenaPlan';

<A100Bays mode="stage" arenaRef={arenaRef} />        // inside my pinned layer, under my wrapper
arenaRef.current?.getBayRect(5)                      // DOMRect, viewport coordinates
```
- `A100Bays` props: `{ mode?: 'static' | 'stage'; arenaRef?: Ref<ArenaPlanHandle> }`. App still renders
  it with no props (= `static`) when CoverStage is missing, and **I render `mode="static"` myself**
  under reduced motion / MOTION OFF / no-JS (the cover stage is not pinned then; brief 2.6).
- `ArenaPlan` props: `{ mode: 'stage' | 'static' }` + ref (React 19 `ref` prop or `forwardRef`), handle
  `{ getBayRect(n: 1 | 2 | 3 | 4 | 5): DOMRect }`.
- **`getBayRect(5)`** = the box where the **full 1:1 plan frame** of bay 05 is drawn (the same square
  as each R2 bay, i.e. including the dark margin outside the yellow border; plan frames are registered
  with the border at 120–1320 of 1440 = `borderRect` 0.0833–0.9167). I land `plan-b44-260` exactly on
  that box (brief H8 / your DoD "matches the pull-out landing within 1 px").

## Stage mode, please
1. **No sheet wrapper.** In `mode="stage"` don't render `id="a-100"` / `data-sheet` (CoverStage owns the
   anchors). `<SheetTag id="A-100"/>` is fine. Exactly one `<h2>` (I forward focus to it after INDEX /
   CTA jumps and add `tabindex="-1"` if it is missing).
2. **Slot 05 empty.** In stage mode render slot 05 as the empty bay box only (hairline / bay outline,
   its label `05 LAYOUT AND MARKING` and its gridline bubble, its link to `#a-105`), **no video and no
   poster**: I put the landed still and then the `plan-b44` film (from 2.60 s, plays once, holds) in it
   myself, with a reserved decoder. (That also avoids two `LoopVideo id="plan-b44"` registrations with
   A-105; see the note below.) In **static** mode slot 05 is yours as normal.
3. **CSS hooks** I set on an ancestor element (`.cv-a100`); defaults must be "fully visible" so static
   mode / no-JS / reduced motion need nothing:
   - `--arena-in` (number 0..1): opacity of bays 01–04 (the R2 strip video/poster). Read it as
     `opacity: var(--arena-in, 1)`.
   - `[data-bubbles="in"]` on the ancestor: draw the gridline bubbles 01–05 on (DRAW, 400 ms each,
     staggered 120 ms; your marks already do `data-drawn`). Absent attribute = drawn (static).
     `data-bubbles="out"` = not drawn yet.
   - `[data-print="in"]` / `[data-print="out"]` on the ancestor: the A-100 text (sheet tag, H2, body,
     legend, bay labels, phone list) prints in (opacity, 200 ms linear) on `in`, is at 0 on `out`.
     Absent = visible. Text never travels.
4. **Fit.** At 1440×900 the whole stage-mode composition must fit in the viewport between the header
   (72 px) and the strip (80 px) because it is pinned. On phones it may run taller than the viewport:
   my pinned layer grows and the rest scrolls after the pin releases.
5. Bays stay real `<a>` links (hover/focus chalk-blue outline, ≥44 px). If keyboard focus enters the
   A-100 layer while the stage is still at the hero, I jump the stage to its end so focused links are
   visible.

## Note (also sent to A1 in A2-2)
`videoManager.register(id, …)` keys registrations by manifest id, so two `<LoopVideo id="plan-b44">`
on one page (A-100 static slot 05 and A-105 PLAN 05) would unregister each other. In stage mode the
A-100 one is mine and is not a LoopVideo, so the clash only exists in static mode.
