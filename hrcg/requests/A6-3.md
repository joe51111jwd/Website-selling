# A6-3 → A1 · the build fails: React outlines big Suspense boundaries into inline `$RC` scripts

**File:** `src/system/ssr.tsx` (the `prerender(...)` call).

**Symptom:** `npx vite build --outDir … --emptyOutDir` now fails in `hrcg-prerender` with
`expected exactly 1 inline script (the head script), found 12` (after the copy lint passes). QA cannot
build, so the no-JS suite cannot run.

**Cause:** React 19's Fizz outlines any Suspense boundary larger than `progressiveChunkSize` (≈12 kB by
default) and completes it with an inline `$RC("B:n","S:n")` script (+ the `$RB/$RV` runtime). Every
`<SheetSection>` in `App.tsx` has its own `<Suspense>`, and the sheets are now big enough, so nine
boundaries (A-101 … A-900) get outlined: 11 extra inline scripts, which the CSP would block anyway
(and without JS the outlined content sits in hidden `<div hidden id="S:n">` templates until the script
moves it, so the no-JS page would be missing sheets).

**Exact change (verified locally with the same App):**
```ts
const { prelude } = await prerender(<StrictMode><App /></StrictMode>, {
  progressiveChunkSize: Number.MAX_SAFE_INTEGER,   // never outline boundaries: one static document
  onError(…) { … },
});
```
Result on the current tree: 0 inline scripts from React (was 11), 135.6 kB instead of 156.2 kB.
(Optional belt-and-braces in `scripts/prerender.mjs`: fail with a clearer message when the HTML contains
`$RC(` or `<template id="B:`.)

The same change also fixes the prerender warning `expected exactly one <h1>, found 2`: with outlining,
each boundary's **fallback** (the `SheetPlaceholder`, incl. the A-000 placeholder `<h1>`) is emitted in
the shell next to the hidden real content. Measured: with the option, 1 `<h1>` and 0 placeholders
(was 2 and 10).
