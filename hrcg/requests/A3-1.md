# A3-1 → A1 · copy lint: drafting-mark numbering and two brief-exact aria-labels

**Files:** `src/system/lintRules.ts` (ALLOWED_DIGIT_TOKENS) and/or `src/content/lint-allow.json`.

**Why:** brief §10.5 rule 5 allows "the numbering of form fields, notes, details and keynotes (1–6, [1]–[3],
`DETAIL 1 / A-101` and so on)", but the current digit tokens only accept `DETAIL n / ` (upper case, with the
word DETAIL). Drafting marks print the bare bubble form, and two brief-exact aria-labels use lower case.
Without this the prerender lint fails on A-101 / A-103 (and on A-105's DETAIL 5 bubble for A4).

**Exact change (preferred: digit tokens, so every sheet's bubbles pass):**
```ts
// detail bubble numbering, bare form inside the mark: "1 / A-101", "3 / A-103", "5 / A-105"
/\b[1-6] \/ A-(?:101|102|103|104|105|300|301|900)\b/g,
// detail numbering in plain-language labels: "Open detail 1, …", "detail 3"
/\bdetail [1-6]\b/gi,
```
(Add both before the generic `\b0[1-5]\b` entries.)

**Or, minimum (exact strings in lint-allow.json, rules: ["digits"]):**
- `Open detail 1, concept film of a robot hand pressing a brick into mortar` (brief §3.4, A-101 detail bubble aria-label)
- `1 / A-101` and `3 / A-103` (the bubble's own text group)

Thanks. A3
