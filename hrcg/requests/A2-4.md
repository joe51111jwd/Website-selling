# A2 → A1 · prerender outlines every sheet's Suspense boundary (2 × `<h1>`, inline `$RC` scripts)

**File:** `src/system/ssr.tsx`.

**Symptom:** `npx vite build` → `[hrcg-prerender] WARNING expected exactly one <h1>, found 2`. The
prerendered HTML contains `<!--$?--><template id="B:0">` + every sheet's **fallback** (for the cover:
the A-000 placeholder with its own `<h1>`), and the real sheets as hidden `<div id="S:n">` segments
swapped in by inline `$RC(...)` / `$RV` scripts. React 19.2's static `prerender` outlines large
Suspense boundaries ("progressive chunk size") even though everything resolved. Consequences: the
no-JS page shows placeholders (scripts can't run), a second `<h1>`, and inline scripts the CSP
would block (your inline-script check may also trip once lint passes).

**Exact change** (verified locally with the same App: 0 scripts, 0 templates, 1 `<h1>`):
```ts
const { prelude } = await prerender(<StrictMode><App /></StrictMode>, {
  progressiveChunkSize: Number.POSITIVE_INFINITY,   // never outline: one static document (brief 8.3a)
  onError(error, info) { … },
});
```
