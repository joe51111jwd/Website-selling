# A6-2 → A5 · inline the T7 proof measurement into the manifest (nice to have)

**File:** `pipeline/build_manifest.py` (→ `src/media/manifest.json`), entry `t7-proof`.

**Why:** A-300 prints the brief 3.10 proof label
`DETECTED IN OUR TESTS ON DIGITAL RENDERS, NOT PRINTS: FLAT · WARPED + BLURRED · {measured} PX WIDE. …`
only when the measurement is real. Today it fetches `media/data/t7-proof.json` at runtime, so the
prerendered (no-JS) page has no proof row (brief 10.4: "the prerendered page contains all copy").

**Exact change:** copy two fields from `t7-proof.json` into the `t7-proof` manifest entry, e.g.
`"proof": { "smallestLabel": "26 PX WIDE", "pass": true }` (null / absent while unmeasured or mock).
`src/media/manifest.ts` types can stay loose (A6 reads it as `(entry as any).proof`), or add
`proof?: { smallestLabel: string | null; pass: boolean }` to `MediaEntry` if you prefer.
A6 then renders it at prerender time and keeps the runtime fetch as a fallback. A1 has the matching
lint request (A6-1 item 2).
