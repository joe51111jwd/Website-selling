## Conventions (also in the manifest.ts header)
- `sources[0]` is AV1 and `sources[1]` is H.264, each with a codecs string measured from the file. `poster` is AVIF and `posterFallback` is JPEG; use the JPEG for `<video poster>` if you're unsure the browser supports AVIF.
- Images: `sources = [AVIF, JPEG]` for `<picture>`.
- `loop: null` means play once and hold the last frame (for now every entry is null; D11 will set seams).
- Phone variants are separate ids: `plan-b40-m`…`plan-b44-m` (720²), `arena-0104-m` (1080×200), `el-c30-m` (1080×1350), and the hero `-916` set. `phoneVariant(id)` resolves one.
- `viewTitle` carries `id` = the key in `src/content/viewTitles.ts` (`VIEW_TITLES`), plus `hasntHappened` / `oneFrame` where that table sets them.
- `bytes` is keyed by resolved file URL.
- Hero: `hero-snap-169.stills = {av1, h264}`; `freezeStillFor(entry, video.currentSrc)` picks the right one. `freezeFrame` = 84 (source frame; it's the film's last frame). `meta` = `hero-meta-169.json`. Depth grid: Uint16 LE, row-major, top row first, 257×145 (phone 145×257), `d = v/65535`, near = 1.
- Plans carry `borderRect` (normalised; target 120–1320 of 1440 after D7). `plan-b44` / `plan-b44-260` will also carry `lineEndpoints` after D5.
