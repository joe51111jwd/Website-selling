## The layout to measure (frame fractions of W × H; the font is your `bs-h1.ttf` = public/fonts/BigShoulders-H1.woff2)
font px = size × H; letter-spacing −0.005 em; kerning on; uppercase strings as below.

| line | text | anchor | 16:9 x | 16:9 baseline | 9:16 x | 9:16 baseline |
|---|---|---|---|---|---|---|
| FAR 1 | `WHAT CAN A` | left-baseline | 0.12 | 0.24480 | 0.08 | 0.16000 |
| FAR 2 | `HUMANOID` | left-baseline | 0.12 | 0.35746 | 0.08 | 0.22450 |
| NEAR 1 | `ACTUALLY` | right-baseline | 0.885 | 0.64234 | 0.865 | 0.71050 |
| NEAR 2 | `BUILD?` | right-baseline | 0.885 | 0.75500 | 0.865 | 0.77500 |

size = 0.131 (16:9) / 0.075 (9:16). Baselines: FAR 1 = cap-top 0.14 (0.10) + 0.8 em; each next line
+0.86 em. NEAR 2 sits 0.005 above the line (y 0.76 / 0.78); NEAR 1 is 0.86 em above it.

In code (your `layout()`), with `cap = 0.8 * font_px`, `step = 0.86 * font_px`:
```py
if PH:
    fx, nx = 0.08 + far_dx, 0.865 + near_dx
    fb1 = (0.10 + far_dy) * H + cap; nb2 = (0.775 + near_dy) * H
else:
    fx, nx = 0.12 + far_dx, 0.885 + near_dx
    fb1 = (0.14 + far_dy) * H + cap; nb2 = (0.755 + near_dy) * H
far  = [('WHAT CAN A', fx * W, fb1, 'ls'), ('HUMANOID', fx * W, fb1 + step, 'ls')]
near = [('ACTUALLY', nx * W, nb2 - step, 'rs'), ('BUILD?', nx * W, nb2, 'rs')]
```
